
# 🌸 Glow Guide — Sprint 1 Project Roadmap 💗

## Project Overview
Glow Guide is a personalized skincare tracking website
designed to help users create morning and nighttime
skincare routines, organize products, and track their
skin's progress.

Our goal is to create a cute, interactive, and
user-friendly website that makes skincare routines
easier to manage.

We definitely plan to use Python, Flask, HTML, and CSS
to develop Glow Guide.

### Why We Chose Radiant
We chose Radiant because it is very similar to what
we envision for Glow Guide. It focuses on skincare
routines and tracking skin progress, which are two
of the main features we want in our application.

We want to explore Radiant's code to understand
how its developers built the application and see
if we could try something similar for Glow Guide.

### Technologies We Plan to Use

create our website.
