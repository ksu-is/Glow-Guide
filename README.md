
# Glow Guide: A Personalized Skincare Routine Tracker 🌸

## Project Description
Glow Guide is a skincare tracking website designed to help users stay organized and consistent with their skincare routines.

The application is especially designed for college students, skincare beginners, and anyone interested in developing better skincare habits.

My goal is to make skincare easier, more enjoyable, and less overwhelming by keeping everything organized in one place.

## Planned Features
- **Morning and Nighttime Routines:** Create and manage personalized skincare routines.
- **Product Tracker:** Organize skincare products by name, brand, and expiration date.
- **Skincare Journal:** Record breakouts, dryness, irritation, and skin improvements.
- **Progress Tracker:** Monitor daily skincare routines and consistency.
- **Product Reminders:** Receive reminders when skincare products are approaching their expiration dates.

## Technologies Used
- **Python:** Handles the application's main functions.
- **Flask:** Creates the interactive web application.
- **HTML:** Structures the website's pages.
- **CSS:** Styles the website to create a cute, clean, and user-friendly design.

## Target Audience
Glow Guide is designed for:
- College students with busy schedules.
- Skincare beginners learning to build routines.
- Young adults interested in skincare and self-care.
- Anyone who wants to improve their skincare consistency.

## Project Goals
1. Create a simple and interactive skincare tracking website.
2. Allow users to personalize their skincare routines.
3. Help users stay consistent with their skincare habits.
4. Provide a way to track skincare products and skin progress.
5. Design an attractive and easy-to-navigate website.
